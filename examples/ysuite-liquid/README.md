# ysuite-liquid

The ysuite-web “Liquid Glass on Metal” mock as a running theme.

Full-bleed glass strip, 28pt capsule pills with traveling sheen, Apple menu and the menus/workspace swap (4pt crossfade) on the left. On the right, left to right: CPU sparkline, Wi-Fi, Bluetooth, battery capsule, clock. Battery popup mirrors the mock (24h/10d history, last charged); CPU popup adds a Disk · ↓ · ↑ footer.

```sh
ybar theme use ysuite-liquid
```

Needs `examples/sketchybar-port` beside this directory.
