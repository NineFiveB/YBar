# ysuite-liquid

The ysuite-web “Liquid Glass on Metal” mock as a running theme.

Full-bleed glass strip, 28pt capsule pills, Apple menu and the menus/workspace swap on the left. On the right, left to right: CPU sparkline, Wi-Fi, Bluetooth, battery, clock. Popups are the real port widgets (calendar grid, gauges, Wi-Fi picker, Bluetooth, battery), not the webpage’s two-row stubs.

```sh
ybar theme use ysuite-liquid
```

Needs `examples/sketchybar-port` beside this directory.
